# School Assessment Calendar

Flutter mobile application for managing and monitoring upcoming academic assessments.

## Overview

The app helps students register, review, edit and share assessments while providing a dashboard focused on the next days of academic workload.

## Features

- assessment creation and editing
- assessment detail view
- delete-by-swipe interactions
- date and form validation
- difficulty level tracking
- dashboard for upcoming assessments
- average difficulty indicators
- share functionality
- unit tests

## Tech stack

- Flutter
- Dart
- Mobile UI development
- Form validation
- Unit testing
